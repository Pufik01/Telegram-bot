# 🤖 Многофункциональный Telegram Бот

Многофункциональный AI-бот с 6 основными режимами работы.

## 📋 Функционал

### 1. 🤖 ИИ Ассистент
- Ответы на любые вопросы
- Помощь в решении задач
- Использует Cerebras API (Llama 3.1)

### 2. ⏰ Напоминания
- Создание напоминаний по времени
- Пример: "напомни мне в 16:38 пойти в больницу"
- Автоматическая отправка уведомлений

### 3. 💚 Психологическая поддержка (первая линия)
- Техники дыхания (4-7-8)
- Рефрейминг
- Список экстренных контактов
- **Важно:** не заменяет профессиональную терапию

### 4. 📊 Трекер привычек
- Добавление/удаление привычек
- Отметка выполнения
- Статистика по привычкам
- Мотивация и прогресс

### 5. 🎯 Бот-консилиум
- Анализ сложных ситуаций
- 5 перспектив: Прагматик, Эмпат, Инвестор, Консерватор, Новатор
- Рекомендации для каждой перспективы

### 6. 💼 Магазин услуг
- Прайс-лист на все функции
- Информация об оплате
- Контакты менеджера

## 🚀 Установка

### 1. Клонирование репозитория
```bash
git clone <repository_url>
cd <repository_name>
```

### 2. Установка зависимостей
```bash
pip install -r Requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `env.example`:
```bash
cp env.example .env
```

Заполните `.env` своими данными:
```env
TG_BOT_TOKEN=your_telegram_bot_token_here
AI_API_KEY=your_cerebras_api_key_here
```

### 4. Запуск бота
```bash
python bot.py
```

## 📝 Получение токенов

### Telegram Bot Token
1. Откройте @BotFather в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте полученный токен

### Cerebras API Key
1. Зарегистрируйтесь на https://cloud.cerebras.ai/
2. Создайте API ключ в личном кабинете
3. Скопируйте ключ в `.env`

## 🎮 Использование

1. Запустите бота командой `/start`
2. Выберите нужный режим из меню кнопок
3. Следуйте инструкциям для каждого режима

### Примеры использования:

**Напоминания:**
```
напомни мне в 16:38 пойти в больницу
```

**Трекер привычек:**
```
добавь привычку пить воду
выпил воду
статистика
```

**Бот-консилиум:**
Опишите вашу дилемму, например:
```
Стоит ли мне менять работу на более высокооплачиваемую, но с большим стрессом?
```

## 🔧 Технологии

- **aiogram 3.x** - фреймворк для Telegram ботов
- **Cerebras API** - AI модель Llama 3.1
- **SQLite** - хранение данных
- **APScheduler** - планировщик напоминаний
- **httpx** - HTTP клиент для API запросов
